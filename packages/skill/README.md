# bsv-dev skill

`bsv-dev` is an Agent Skills skill for building BSV applications with an AI coding agent, testnet first. It gives the agent an end-to-end playbook: choosing who holds the keys (custody shape A or B), connecting a BRC-100 wallet, BRC-29 payments, reading transaction state from Arcade (final at `SEEN_ON_NETWORK` with no competing transaction), and taking an app from testnet to mainnet. It works on its own and works better with the `@bsv/mcp` server and the BSV docs MCP installed.

The skill never asks for, stores or generates production private keys, and it never edits your agent configuration: when an MCP server is missing it prints the install command for you to run.

## Install

Any agent that reads Agent Skills:

```bash
npx skills add bsv-blockchain/bsv-ai-toolkit
```

Claude Code plugin (the skill plus both MCP servers):

```bash
claude plugin marketplace add bsv-blockchain/bsv-ai-toolkit && claude plugin install bsv-dev@bsv
```

The plugin needs Claude Code v2.1.271 or later (its network setting is a fixed `testnet`/`mainnet` choice). It adds `/bsv-review [path]` and `/bsv-design [app name]`, and asks for two settings: the network (default `testnet`) and an optional Arcade URL. Mainnet broadcasts by the agent also need `BSV_MCP_ALLOW_MAINNET_BROADCAST=1` in your shell; the plugin never sets it.

The MCP servers on their own, in Claude Code:

```bash
claude mcp add --transport http bsv-docs https://bsv.writedocs.io/mcp
claude mcp add bsv-mcp -e BSV_NETWORK=testnet -- npx -y @bsv/mcp
```

`./install.sh` prints these commands plus the Codex lines and a JSON snippet for Cursor, Windsurf and VS Code. It only prints; it writes nothing.

## Generated and authored files

Everything lives under `skills/bsv-dev/`.

| File | Kind |
| --- | --- |
| `SKILL.md` | Authored |
| `references/facts.md`, `guardrails.md`, `stack.md`, `custody-shapes.md`, `threat-model.md` | Generated by `pnpm sync` from the repository's `content/`; never edit them here. Edit `content/` and re-run `pnpm sync`. |
| Other `references/*.md` | Authored judgment files (wallet, payments, Arcade, routing, mainnet, errors) |

Generated files start with a `generated by packages/sync` comment, and CI fails when they drift from `content/`.

## Tests

From the repository root:

```bash
pnpm -F bsv-dev-skill test                        # structure tests, offline
SKILLS_REF_TESTS=1 pnpm -F bsv-dev-skill test     # also runs skills-ref validate (fetches it with npx)
CLAUDE_CLI_TESTS=1 pnpm -F bsv-dev-skill test     # also runs claude plugin validate --strict (needs the claude CLI)
pnpm -F bsv-dev-skill validate                    # skills-ref validate on its own
bash scripts/anti-goals.sh packages/skill/skills  # forbidden phrasings appear only as "never" lines
```
